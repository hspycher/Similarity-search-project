# AWS deployment — Fashion Similarity Search

Provisions a single EC2 instance in **us-west-2** that runs the Streamlit app
on port 8501 and queries the existing Qdrant collection at
`http://16.144.140.219:6333` (collection `deepfashion_items`).

## Files

| File             | Purpose                                                      |
|------------------|--------------------------------------------------------------|
| `deploy.ps1`     | **Windows** — provisions key pair, SG, and EC2 instance.     |
| `teardown.ps1`   | **Windows** — terminates the instance and deletes the SG.   |
| `deploy.sh`      | macOS/Linux equivalent of `deploy.ps1`.                      |
| `teardown.sh`    | macOS/Linux equivalent of `teardown.ps1`.                    |
| `user-data.sh`   | Cloud-init script that installs deps and starts the app.     |
| `deploy.state`   | Generated by deploy; consumed by teardown.                   |

## Prerequisites

- AWS CLI v2 installed and authenticated (`aws configure` or `AWS_PROFILE`).
- An IAM identity with EC2 permissions (`ec2:*` is sufficient).
- A default VPC in the target region (us-west-2 has one out of the box).
- **Windows only:** PowerShell 5.1+ (built in) and the OpenSSH client
  (built into Windows 10 1809+ — verify with `ssh -V`). If `ssh` is missing:
  `Settings → Apps → Optional Features → Add → OpenSSH Client`.

## Quickstart — Windows (PowerShell)

Open PowerShell in the `deploy\` directory:

```powershell
cd deploy

# One-time: allow running local scripts in this PowerShell session
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# Deploy with defaults (us-west-2, t3.medium, :8501 open to internet)
.\deploy.ps1

# Or: lock :8501 down to your current public IP
.\deploy.ps1 -MyIp auto

# Or: tweak region / size
.\deploy.ps1 -Region us-east-1 -InstanceType t3.large -MyIp auto
```

When `deploy.ps1` finishes it prints the public URL, e.g.
`http://54.123.45.67:8501`. First boot takes ~5–8 minutes while torch + CLIP
download and install. Watch progress with:

```powershell
ssh -i fashion-search-key.pem ubuntu@<PUBLIC_IP> "sudo tail -f /var/log/cloud-init-output.log"
```

The script automatically locks `fashion-search-key.pem`'s ACLs to the current
user — required by Windows OpenSSH (it refuses to use keys readable by others).

### Tear down (Windows)

```powershell
.\teardown.ps1
```

## Quickstart — macOS / Linux (bash)

```bash
cd deploy
chmod +x deploy.sh user-data.sh teardown.sh

./deploy.sh                                              # open to internet
# or:  MY_IP="$(curl -s https://checkip.amazonaws.com)/32" ./deploy.sh

./teardown.sh
```

Both deploy paths terminate the instance and delete the security group on
teardown. The key pair is intentionally kept; comments in the teardown
scripts show how to also delete it.

## Configuration knobs

PowerShell uses named parameters; bash uses environment variables. Same
defaults either way.

| PowerShell param  | Bash env var     | Default                        | Notes                                    |
|-------------------|------------------|--------------------------------|------------------------------------------|
| `-Region`         | `REGION`         | `us-west-2`                    | AWS region.                              |
| `-InstanceType`   | `INSTANCE_TYPE`  | `t3.micro`                     | Free-tier eligible (1 GB RAM). user-data adds 4 GB swap. Use `t3.medium` for snappier inference. |
| `-KeyName`        | `KEY_NAME`       | `fashion-search-key`           | Created if missing; .pem written locally.|
| `-SgName`         | `SG_NAME`        | `fashion-search-sg`            | Reused if it already exists.             |
| `-MyIp`           | `MY_IP`          | `0.0.0.0/0`                    | Restrict :8501 to a single CIDR. PowerShell accepts `auto`. |
| `-SshCidr`        | `SSH_CIDR`       | `0.0.0.0/0`                    | Restrict :22 to a single CIDR.           |
| `-RepoUrl`        | `REPO_URL`       | dongyansun/Similarity-search-… | Override to deploy a fork or branch.     |
| `-RootVolumeGb`   | `ROOT_VOLUME_GB` | `30`                           | Disk size; torch + CLIP weights ~3 GB.   |

## How it talks to Qdrant

`src/config.py` already points at `http://16.144.140.219:6333` and the
`deepfashion_items` collection. The EC2 instance reaches Qdrant over the
public internet — no peering needed.

If `16.144.140.219:6333` is later locked down (security group, IP allow-list),
add the EC2 instance's public IP (or a NAT gateway elastic IP) to that
allow-list. The deploy output prints the IP.

## Caveats

- **Filter sidebar is sparse.** The Streamlit app's metadata filter dropdowns
  are populated from a *local* Myntra `styles.csv`. We're not shipping that
  44k-row CSV to the box; `user-data.sh` writes a one-row stub so the app
  boots. **Image-upload search and text search work normally** — both query
  Qdrant directly. If you want the full filter list, sync the real
  `archive (1)/` folder onto the instance after first boot.

  **Windows (PowerShell):**
  ```powershell
  scp -i fashion-search-key.pem -r "..\archive (1)" ubuntu@<PUBLIC_IP>:/home/ubuntu/Similarity-search-project/
  ssh -i fashion-search-key.pem ubuntu@<PUBLIC_IP> "sudo systemctl restart fashion-search"
  ```

  **macOS/Linux (bash):**
  ```bash
  scp -i fashion-search-key.pem -r "../archive (1)" \
      ubuntu@<PUBLIC_IP>:/home/ubuntu/Similarity-search-project/
  ssh -i fashion-search-key.pem ubuntu@<PUBLIC_IP> 'sudo systemctl restart fashion-search'
  ```

- **CPU-only torch.** The user-data installs the CPU wheels of torch /
  torchvision (~200 MB instead of ~2 GB). CLIP encoding of a single query
  image on t3.medium takes ~1 second — fine for interactive search.

- **No HTTPS.** This is plain HTTP on :8501. For anything beyond a demo,
  put the instance behind an ALB with ACM cert, or terminate TLS in nginx.
